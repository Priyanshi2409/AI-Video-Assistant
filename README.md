# 🎥 AI Video Assistant

An AI-powered Video Assistant that processes videos, extracts audio, transcribes speech into text, generates summaries, and enables intelligent question answering using Retrieval-Augmented Generation (RAG).

## 🚀 Features

- 🎙️ Extract audio from video files
- 📝 Convert speech to text (Transcription)
- 📄 Generate concise summaries
- 🔍 RAG-based intelligent question answering
- 🗂️ Vector database for efficient retrieval
- 📦 Modular and scalable project structure

## 🛠️ Technologies Used

- Python
- Whisper
- LangChain
- ChromaDB
- Hugging Face Embeddings
- FFmpeg
- Retrieval-Augmented Generation (RAG)

## ▶️ How to Run

1. Clone the repository
```bash
git clone https://github.com/<your-username>/AI-Video-Assistant.git
```

2. Install dependencies

```bash
pip install -r Requirements.txt
```

3. Run the application

```bash
python main.py
```
